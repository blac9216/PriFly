# Overnight limits

Standing rules for unattended runs:

- work only on planned, sequenced, Ready issues whose dependencies and area locks permit
  dispatch;
- use local or explicitly disposable test resources unless local guidance authorizes a
  named external environment;
- do not mutate production/provider systems, perform owner-confirmation actions, change
  repository permissions, merge, or weaken a conformance oracle unattended;
- do not invent credentials, owner decisions, security exceptions, quality thresholds,
  architecture changes, or vendor behavior to keep a run moving;
- apply `help` and record the blocker when owner authority, unavailable evidence, an
  ambiguous design decision, or unsafe resource collision prevents progress;
- do not broaden an issue to consume unattended time; file newly found work through the
  workflow's deferred-finding path.
