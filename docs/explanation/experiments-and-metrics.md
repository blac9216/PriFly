# Experiments, metrics, and learning

Kind: explanation

PriFly learns through deterministic measurement, controlled experiments, and bounded AI interpretation. Evidence can recommend policy changes; it cannot silently rewrite governing policy.

Experiments are first-class, bounded Factory objects.

New optional Routes may progress:

```text
replay
→ shadow
→ low-risk live
→ broader live
→ Champion candidate
```

Harness security/maintenance updates are applied according to maintenance policy and measured afterward; they are not held back merely because an obsolete version performed better.

### 29.1 Experiment validity

Experiments must predeclare, where applicable:

- eligible population;
- deterministic assignment/stratification;
- analysis unit;
- all-assigned-job denominator;
- failures/abandonments;
- rescue/Fixer attribution;
- observation window;
- missing-data handling;
- quality/safety guardrails;
- stop conditions;
- uncertainty/confidence threshold.

Accepted-only outcomes are not sufficient.

Reviewers themselves require calibration using independent adjudication, seeded cases, or retrospective quality audits before Reviewer leniency can be interpreted as producer quality.

Factory observations produce recommendations, not automatic routing-policy mutation.

## Historical metrics and learning evidence

### Historical metrics

Metrics used for long-term Factory learning are authoritative semantic state and are preserved across host loss.

Examples:

- exact Route/execution manifest;
- tokens/cache where available;
- duration;
- review rounds;
- severe failure/rescue;
- scope expansion;
- verification outcome;
- owner intervention;
- estimate/impact prediction accuracy.

## Initiative lessons

Initiative closure requires:

- terminal released Work Items;
- required validation;
- no unresolved blocking Findings/owner decisions;
- reconciled provider projection;
- explicit residual risks.

Factory computes deterministic delivery/planning metrics, then may run a bounded independently reviewed lessons analysis.

Knowledge promotion remains:

```text
Observation
→ Lesson Candidate
→ reviewed Lesson
→ repeated evidence
→ Recommendation
→ owner/policy decision
```

Factory does not autonomously rewrite Constitution or routing policy.
